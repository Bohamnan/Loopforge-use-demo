## 0. 范围与约定

- **需求边界（人工门控确认）**：本需求为纯前端静态 Mock 用户列表页，不涉及后端 `user` 数据模型或真实 HTTP 接口，不涉及账号登录与权限鉴权（`ADR-009`）；所有列表与详情数据均来自前端运行时内存合成脱敏数据。
- **依据文档**：`01-requirements/HR_PR-2/prd.md`（用户故事 #1~#5）、`frontend-docs/HR_PR-2/00_impact_analysis.md`（回归影响范围与 `TD-13` / `TD-25` / `B-03` / `B-06` / `F-01` / `F-02` 约束）。
- **PERM 权限维度说明**：系统无真实账号与权限体系（`ADR-009`），`role` 仅作为静态数据展示与筛选枚举字段，不存在权限拦截差异，因此本轮 PERM 维度用例数记为 0（范围外）。
- **执行环境约定**：桌面端（`1280×800`）、平板端（`768×1024`）、窄屏移动端（`360×720`，`TD-13`）；配合前端 Vitest 集成测试验证异步延迟、并发过期请求丢弃及详情加载失败回调分支。
