## 失败与阻塞清单（交 bug-fixer）

### BUG-01：360px 窄屏下顶栏因新增第 3 个页签导致标题竖排重叠与右侧操作按钮越界

| 字段 | 内容 |
|---|---|
| **TC_ID** | `TC-QA-REG-02` |
| **所属 Workbench** | `frontend`（`codes/hr-collection-agent-frontend`） |
| **前置条件** | 打开前端 Web 应用（`feature-requirement-7-20261125-0158` @ `0f81f29`），浏览器视口宽度设为 `360×720`（`TD-13` 支持下限）。 |
| **复现步骤** | 1. 在 `360×720` 视口下进入“用户列表”页签，观察 `.app-header` 标题与页面 `<h2>用户列表</h2>`。<br>2. 切回“对话”页签，观察 `.app-header` 标题与右侧 `.app-header-action`（“会话”/“新对话”按钮）。 |
| **预期结果** | 遵循 `TD-13`（窗口宽度 `≥ 360px`），顶栏品牌标题、导航页签与窄屏操作按钮均应正常展示，不发生文字竖排挤压重叠，也不应有按钮被挤出 `360px` 视口边界。 |
| **实际结果** | 1. “用户列表”页签中，`.app-header` 为固定 `height: 56px; padding: 0 24px` 单行 Flex 且无窄屏换行规则；`Segmented` 新增第 3 个页签“用户列表”后占用较多宽度，导致 `<h1>HR 简历信息收集</h1>` 被挤压成逐字竖排折行，向下溢出 `56px` 顶栏并直接重叠在 `<h2>用户列表</h2>` 上。<br>2. “对话”页签中，同样发生 `h1` 竖排溢出，且右侧 `.app-header-action` 中的“会话”按钮超出 `360px` 视口右边界，部分被裁切不可达。 |
| **执行方式** | N/A（真实 Chromium 实机验证） |
| **证据** | `Layout.css` 第 29-45 行（`.app-header` 固定 `height: 56px` 无 `flex-wrap`）、第 569-571 行（`.app-nav` 无窄屏适配）；实机 `360×720` 截图与 DOM 测量（内层表格 `scrollWidth=1179, clientWidth=336` 正常，顶栏标题溢出重叠且右侧按钮裁切）。建议修复方向：在 `@media (max-width: 599px)`（或 `< 860px`）下为 `.app-header` 启用 `height: auto; min-height: 56px; flex-wrap: wrap; padding: 8px 12px;`、为 `.app-header h1` 设置 `white-space: nowrap`、并在窄屏下合理排布 `.app-nav`（例如 `order` 换行占满一行或缩小左右留白）。 |
| **状态** | 待修复 |
