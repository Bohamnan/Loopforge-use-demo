## 一、原型概要

- 布局：顶部导航（Logo、"提交简历 / 填写指南 / 隐私说明"、用户头像"张伟"）+ 左侧会话栏（"＋ 新对话"、历史会话列表）+ 中间对话区 + 底部输入框（📎 上传、拖拽、文字输入）。
- 流程：欢迎页 → 对话内上传 → 分步"思考过程"动画 → 按 6 个分区逐项核对（卡片 + "确认无误"按钮，或用自然语言"字段名改成新值"修改）→ 最终版本卡片 →"确认提交 / 我还要修改"→ 已保存卡片（记录编号、姓名、原始文件、保存时间）。
- 状态标记：黄色表示"把握较低"，另有"已修改"标记。

## 二、与需求一致、可直接采纳的部分

| 原型做法 | 对应需求 / 裁决 |
|---|---|
| 对话式单页流程；欢迎页引导上传；📎 和拖拽上传，只接受 `.pdf,.jpg,.jpeg,.png` | REQ-FE-01、PRD#1 |
| 识别结果以卡片展示，按分区呈现 | REQ-FE-02 |
| 每个分区"确认无误"后进入下一项；"其余都没问题"可跳到最终确认 | REQ-FE-03、D-03 |
| 最终确认前展示完整版本，有独立的"确认提交"；提交成功后才显示已保存 | REQ-FE-04、F-03、D-03 |
| 底部提示"内容由 AI 识别，可能有误，请逐项核对" | B-04 精神 |
| 保存后提示"如需提交另一份，点击新对话" | C-11 |
